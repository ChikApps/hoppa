# Security

Hoppa sees what you type in order to recognize a shortcut, so we take security reports seriously.

## Reporting a security problem

Please write to **office@chiktime.com**. Do not open a public issue for a security problem.

Include in the report:

- the version of Hoppa (shown under "About" in the settings),
- the version of Chrome (or Edge),
- the steps that reproduce the problem.

## What Hoppa is built to guarantee

- No network requests, no server, no data collection. Updates arrive only through the Chrome Web Store.
- Text you typed is checked in memory only. It is never saved, sent or logged.
- Text of a shortcut is always inserted and displayed as text, never as code.
- Hoppa does not work in password, payment-card and one-time-code fields.
- A shortcut is replaced only after real typing on the keyboard, never because a page asked for it.

# אבטחה

Hoppa רואה את מה שמקלידים כדי לזהות קיצור, ולכן אנחנו מתייחסים ברצינות לכל דיווח על בעיית אבטחה.

## איך מדווחים על בעיית אבטחה

כתבו ל-**office@chiktime.com**. אל תפתחו על בעיית אבטחה דיווח ציבורי במאגר.

מה לכלול בדיווח:

- גרסת Hoppa (מופיעה ב"אודות" בהגדרות),
- גרסת כרום (או אדג'),
- הצעדים שמשחזרים את הבעיה.

## מה Hoppa בנוי להבטיח

- בלי בקשות רשת, בלי שרת ובלי איסוף מידע. עדכונים מגיעים רק דרך החנות של כרום.
- מה שהקלדתם נבדק בזיכרון בלבד. הוא לא נשמר, לא נשלח ולא נרשם.
- טקסט של קיצור תמיד מוכנס ומוצג כטקסט, אף פעם לא כקוד.
- Hoppa לא פועל בשדות של סיסמה, כרטיס אשראי וקוד חד-פעמי.
- קיצור מוחלף רק אחרי הקלדה אמיתית במקלדת, אף פעם לא בגלל שדף ביקש.
